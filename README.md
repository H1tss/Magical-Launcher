# 🦄 Magical Launcher

**Magical Launcher** is an enchanted, third-party replacement for the standard Roblox bootstrapper, now powered by pure unicorn magic! ✨ It provides additional mystical features and improvements to enhance your gaming experience.

> 💫 *Where gaming meets magic, and unicorns roam free!* 💫

## ✨ Magical Features

- 🦄 **Unicorn Discord Rich Presence** - Let your friends know you're playing with magical style! Your status now includes sparkles and rainbow effects
- 🌈 **Rainbow Mod Support** - Customize your Roblox experience with enchanted content files (magical death sounds, glittery cursors, etc)
- 🧭 **Mystical Server Location Tracking** - Discover where your gaming server hides geographically (courtesy of [ipinfo.io](https://ipinfo.io))
- 🎨 **Enchanted Graphics Configuration** - Fine-tune your graphics fidelity and UI experience with magical precision
- 💎 **Sparkle Effects** - Everything is more magical with sparkles and glitter!
- 🎪 **Unicorn Theme** - A complete mythical redesign of the entire launcher interface

## 🚀 Installing Magical Launcher

Download the [latest release of Magical Launcher](https://github.com/Halo-tuff/Magical-Launcher/releases/latest), and run it. Configure your mystical preferences if needed, and install. That's about it!

Alternatively, you can install Magical Launcher via [Winget](https://winstall.app/apps/pizzaboxer.Bloxstrap) by running this in a Command Prompt window:
```
> winget install magical-launcher
```

You will also need the [.NET 6 Desktop Runtime](https://aka.ms/dotnet-core-applaunch?missing_runtime=true&arch=x64&rid=win11-x64&apphost_version=6.0.36&gui=true).

### ⚠️ Windows SmartScreen Notice
It's not unlikely that Windows Smartscreen will show a popup when you run Magical Launcher for the first time. This happens because it's an unknown program, not because it's actually detected as being malicious. Just click "More info" and then "Run anyway" to proceed with the magic!

Once installed, Magical Launcher is added to your Start Menu, where you can access the enchanted menu and reconfigure your mystical preferences if needed.
